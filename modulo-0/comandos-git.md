Segun lo que entendi los comandos git que mas voy a usar van de la siguiente manera y a mi entender hacen esto
git clone + url Clonar, sirve para clonar un repositorio en mi pc
git status Estado, sirve para ver que cambio y donde quedo 
git add Añadir, prepara los cambios para el proximo commit
git commit -m "..."  Confirmar, deja prueba de lo hecho con un mensaje en tu pc
git push Empujar, sube tus commits a github
git log --oneline Registo, muestra lo que hiciste osea el historial de los commits una linea a la vez
git pull Jalar, es para traer los cambios hechos en Github a mi pc
